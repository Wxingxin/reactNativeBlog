# 一、先搭好「正确的工程骨架」（1.3 关键工程点）

> ❗这是很多人学 Query 最大的坑：
> **API、Query Key、QueryClient 没统一，后期必乱**

---

## 1️⃣ 统一封装 API 层（fetch / axios）

### 目录结构（推荐）

```txt
src/
├─ api/
│  ├─ http.ts        # axios/fetch 实例
│  └─ user.api.ts    # 具体业务 API
```

---

### `api/http.ts`

```ts
import axios from "axios";

export const http = axios.create({
  baseURL: "/api",
  timeout: 10000,
});

http.interceptors.response.use(
  (res) => res.data,
  (err) => Promise.reject(err)
);
```

👉 Query **永远只调用 api 层函数**，不直接写 fetch/axios

---

### `api/user.api.ts`

```ts
import { http } from "./http";

export const getUsers = (params) =>
  http.get("/users", { params });

export const getUserDetail = (id) =>
  http.get(`/users/${id}`);

export const createUser = (data) =>
  http.post("/users", data);

export const updateUser = (id, data) =>
  http.put(`/users/${id}`, data);

export const deleteUser = (id) =>
  http.delete(`/users/${id}`);
```

---

## 2️⃣ Query Key 统一管理（必须做）

### `queryKeys/user.keys.ts`

```ts
export const userKeys = {
  all: ["users"] as const,

  lists: () => [...userKeys.all, "list"] as const,
  list: (params) => [...userKeys.lists(), params] as const,

  details: () => [...userKeys.all, "detail"] as const,
  detail: (id) => [...userKeys.details(), id] as const,
};
```

👉 **任何 useQuery / invalidate 都从这里拿 key**

---

## 3️⃣ 配置 QueryClient（默认策略）

### `main.tsx / index.tsx`

```ts
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      retry: 1,
      staleTime: 5 * 60 * 1000,
      gcTime: 10 * 60 * 1000,
      refetchOnWindowFocus: false,
    },
  },
});
```

# 二、列表页（搜索 + 筛选 + 刷新）

> 这是 **TanStack Query 使用频率最高的页面**

---

## 1️⃣ 页面需求

* 搜索关键字
* 筛选状态
* 点击刷新
* 参数变化 → 自动请求

---

## 2️⃣ 列表页完整代码

```tsx
function UserListPage() {
  const [search, setSearch] = useState("");
  const [status, setStatus] = useState("all");

  const params = { search, status };

  const {
    data: users,
    isLoading,
    refetch,
  } = useQuery({
    queryKey: userKeys.list(params),
    queryFn: () => getUsers(params),
    keepPreviousData: true,
  });

  return (
    <>
      <input value={search} onChange={(e) => setSearch(e.target.value)} />
      <select value={status} onChange={(e) => setStatus(e.target.value)}>
        <option value="all">全部</option>
        <option value="active">启用</option>
      </select>

      <button onClick={() => refetch()}>刷新</button>

      {isLoading && <p>加载中...</p>}
      {users?.map((u) => (
        <div key={u.id}>{u.name}</div>
      ))}
    </>
  );
}
```

---

## 3️⃣ 你必须理解的点

* **搜索 / 筛选 ≠ 手动请求**
* 参数进 Query Key → 自动缓存 & 自动刷新
* `refetch()` = 手动刷新按钮

# 三、详情页（根据 id 获取详情）

> Query 的 **enabled 场景必考**

---

## 1️⃣ 详情页代码

```tsx
function UserDetailPage() {
  const { id } = useParams();

  const { data, isLoading } = useQuery({
    queryKey: userKeys.detail(id),
    queryFn: () => getUserDetail(id),
    enabled: !!id,
  });

  if (isLoading) return <p>加载中...</p>;

  return <div>{data.name}</div>;
}
```

---

## 2️⃣ 核心原则

> **没有 id → 不请求**

* enabled = false
* Query 彻底不执行
* 避免 undefined 请求

# 四、新增 / 编辑页（mutation + 刷新 / 跳转）

---

## 1️⃣ 新增用户

```tsx
function CreateUserPage() {
  const queryClient = useQueryClient();
  const navigate = useNavigate();

  const mutation = useMutation({
    mutationFn: createUser,
    onSuccess: (data) => {
      queryClient.invalidateQueries({
        queryKey: userKeys.lists(),
      });
      navigate(`/users/${data.id}`);
    },
  });

  return (
    <button
      onClick={() =>
        mutation.mutate({ name: "Tom" })
      }
    >
      新增
    </button>
  );
}
```

---

## 2️⃣ 编辑用户

```ts
useMutation({
  mutationFn: ({ id, data }) => updateUser(id, data),
  onSuccess: (_, variables) => {
    queryClient.invalidateQueries({
      queryKey: userKeys.detail(variables.id),
    });
    queryClient.invalidateQueries({
      queryKey: userKeys.lists(),
    });
  },
});
```

---

## 3️⃣ 你要形成的条件反射

> **改了数据 → invalidate 对应 key**

* 列表 → invalidate list
* 详情 → invalidate detail

# 五、删除（invalidate / cache 更新）

---

## 1️⃣ 最简单（推荐新手）

```ts
useMutation({
  mutationFn: deleteUser,
  onSuccess: () => {
    queryClient.invalidateQueries({
      queryKey: userKeys.lists(),
    });
  },
});
```

---

## 2️⃣ 进阶（直接改缓存，不卡）

```ts
onSuccess: (_, id) => {
  queryClient.setQueryData(
    userKeys.lists(),
    (old) => old?.filter((u) => u.id !== id)
  );
};
```
