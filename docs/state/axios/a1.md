## 1.1 安装与基础调用

### 1.1.1 安装

```bash
npm i axios
# 或
pnpm add axios
# 或
yarn add axios
```

在 React 里使用（任意组件/模块）：

```js
import axios from "axios";
```

---

### 1.1.2 axios.get / post / put / patch / delete（最常用）

它们本质都是 `axios(config)` 的语法糖。

#### GET：查（带 querystring）

```js
// GET /users?page=1&pageSize=10
axios.get("/users", {
  params: { page: 1, pageSize: 10 },
});
```

#### POST：增（body 在 data）

```js
// POST /users  body: { name: "Tom" }
axios.post("/users", { name: "Tom" });
```

#### PUT：全量更新（通常要求提供完整资源）

```js
// PUT /users/1 body: { id: 1, name: "Tom", age: 20 }
axios.put("/users/1", { id: 1, name: "Tom", age: 20 });
```

#### PATCH：部分更新（只传要改的字段）

```js
// PATCH /users/1 body: { name: "Jerry" }
axios.patch("/users/1", { name: "Jerry" });
```

#### DELETE：删（有些后端 delete 也支持 body，但不通用）

```js
// DELETE /users/1
axios.delete("/users/1");
```

---

### 1.1.3 axios({ method, url, params, data, headers })（通用写法）

当你需要统一封装、动态 method、或者更复杂配置时，用这个。

```js
axios({
  method: "post",
  url: "/users",
  params: { debug: 1 },        // -> 拼到 URL 上 ?debug=1
  data: { name: "Tom" },       // -> 请求体
  headers: { "X-Trace-Id": "abc" },
});
```

---

### 1.1.4 params（querystring） vs data（request body）

这是你必须“条件反射”的点：

* **params**：拼在 URL 后面（querystring），常用于 **过滤/分页/搜索**
  `GET /items?keyword=abc&page=1`
* **data**：请求体（body），常用于 **提交表单、创建/更新资源**
  `POST /items` body `{ title: "xx" }`

直观对比：

```js
// params -> /posts?userId=1
axios.get("/posts", { params: { userId: 1 } });

// data -> body 里
axios.post("/posts", { title: "Hello", body: "..." });
```

## 1.2 常用配置项（必须熟）

下面这些配置你会在“axios 实例”或单次请求里用到。

### 1.2.1 baseURL（推荐：用 axios.create 固定）

```js
const api = axios.create({
  baseURL: "https://api.example.com",
});
api.get("/users"); // 实际请求 https://api.example.com/users
```

### 1.2.2 timeout（超时毫秒）

```js
axios.get("/users", { timeout: 8000 });
```

超时通常会进入 `catch`，属于“请求失败”。

### 1.2.3 headers（请求头）

```js
axios.get("/users", {
  headers: {
    Authorization: "Bearer tokenxxx",
  },
});
```

### 1.2.4 withCredentials（Cookie/跨域携带凭证）

当你用 **Cookie** 做登录态，并且请求是跨域时常用：

```js
axios.get("https://api.example.com/profile", {
  withCredentials: true,
});
```

注意：这需要后端 CORS 也允许携带凭证（`Access-Control-Allow-Credentials: true` 等）。

### 1.2.5 responseType（blob/arraybuffer/json）

* 默认 `json`
* 下载文件用 `blob`

```js
// 下载文件
axios.get("/files/report.pdf", { responseType: "blob" });
```

### 1.2.6 validateStatus（自定义哪些状态码算“成功”）

Axios 默认认为 **2xx** 才算成功；否则进入 catch（`error.response` 有值）。

你可以改成比如：`< 500` 都算成功（让 4xx 也走 then，自己处理）：

```js
axios.get("/something", {
  validateStatus: (status) => status < 500,
});
```

生产里一般不需要乱改，除非你明确知道你要统一处理 4xx 并保持 then 流程。

## 1.3 错误处理模型（关键）

Axios 的错误基本分三类，你要能区分并提示不同文案：

### A. error.response：服务端“回了响应”，但状态码不在成功范围（如 400/401/500）

你能拿到：

* `error.response.status`
* `error.response.data`
* `error.response.headers`

### B. error.request：请求发出去了，但没收到响应（网络断开、DNS、CORS 被挡、服务挂了、超时等）

通常表现为：

* `error.request` 有值
* `error.response` 为空

### C. error.message：其他错误（配置错误、代码异常、取消请求等）

比如 url 写错、参数类型问题等。

最稳的处理方式是写一个 `parseAxiosError` 函数统一解析。

## 代码 1：`src/api/http.js`

```js
import axios from "axios";

export const api = axios.create({
  baseURL: "https://jsonplaceholder.typicode.com",
  timeout: 10000,
  headers: {
    "Content-Type": "application/json",
  },
  // 默认即可：2xx 才算成功
  // validateStatus: (status) => status >= 200 && status < 300,
});

// 统一错误解析：输出 { type, message, status, data }
export function parseAxiosError(error) {
  // 1) 服务端响应非 2xx
  if (error.response) {
    const status = error.response.status;
    const data = error.response.data;

    // 业务错误：很多公司后端会 200 但 code != 0，这里先不做（后面拦截器阶段做）
    // 这里先把 HTTP 错误当作“服务端错误/请求错误”
    let msg = "请求失败";
    if (status === 401) msg = "登录已过期或无权限（401）";
    else if (status === 403) msg = "无权限访问（403）";
    else if (status === 404) msg = "资源不存在（404）";
    else if (status >= 500) msg = "服务器异常，请稍后重试";
    else msg = `请求错误（${status}）`;

    return { type: "http", message: msg, status, data };
  }

  // 2) 请求发出但无响应（网络、超时、CORS等）
  if (error.request) {
    // 超时的错误 message 通常包含 timeout
    const isTimeout = String(error.message || "").toLowerCase().includes("timeout");
    return {
      type: "network",
      message: isTimeout ? "请求超时，请检查网络或稍后重试" : "网络异常，未收到服务器响应",
    };
  }

  // 3) 其他错误（配置、代码等）
  return {
    type: "unknown",
    message: error.message || "未知错误",
  };
}
```

## 代码 2：`src/pages/AxiosCrudDemo.jsx`

```jsx
import React, { useEffect, useMemo, useState } from "react";
import { api, parseAxiosError } from "../api/http";

// 一个极简 toast（无需第三方库）
function Toast({ toast, onClose }) {
  if (!toast) return null;
  return (
    <div
      style={{
        position: "fixed",
        right: 16,
        top: 16,
        padding: "12px 14px",
        border: "1px solid #ddd",
        borderRadius: 8,
        background: "#fff",
        boxShadow: "0 6px 20px rgba(0,0,0,0.08)",
        maxWidth: 360,
        zIndex: 9999,
      }}
    >
      <div style={{ fontWeight: 600, marginBottom: 6 }}>{toast.title}</div>
      <div style={{ fontSize: 14, lineHeight: 1.5 }}>{toast.message}</div>
      <button
        style={{ marginTop: 10 }}
        onClick={onClose}
      >
        关闭
      </button>
    </div>
  );
}

export default function AxiosCrudDemo() {
  const [loading, setLoading] = useState(false);
  const [posts, setPosts] = useState([]);
  const [toast, setToast] = useState(null);

  // 表单状态：创建 / 更新
  const [title, setTitle] = useState("");
  const [body, setBody] = useState("");

  const showToast = (title, message) => setToast({ title, message });

  // 统一请求包装：自动处理错误 toast
  async function safeRequest(fn) {
    try {
      setLoading(true);
      const res = await fn();
      return res;
    } catch (err) {
      const parsed = parseAxiosError(err);
      showToast("请求失败", parsed.message);
      // 你也可以 console.log(parsed) 观察结构
      console.error("Axios error parsed:", parsed, err);
      return null;
    } finally {
      setLoading(false);
    }
  }

  // R: Read 列表（带 params 示例）
  async function fetchPosts() {
    const res = await safeRequest(() =>
      api.get("/posts", {
        params: { _limit: 10 }, // querystring 示例：/posts?_limit=10
      })
    );
    if (!res) return;
    setPosts(res.data);
    showToast("成功", "已加载列表（GET + params）");
  }

  // C: Create
  async function createPost() {
    if (!title.trim()) return showToast("提示", "title 不能为空");

    const res = await safeRequest(() =>
      api.post("/posts", {
        title,
        body,
        userId: 1,
      })
    );
    if (!res) return;

    // jsonplaceholder 会返回一个模拟的 id
    setPosts((prev) => [{ ...res.data }, ...prev]);
    setTitle("");
    setBody("");
    showToast("成功", "已创建（POST + data）");
  }

  // U: Update（PUT 示例：全量更新）
  async function updateFirstPost() {
    if (posts.length === 0) return showToast("提示", "列表为空，无法更新");
    const first = posts[0];

    const res = await safeRequest(() =>
      api.put(`/posts/${first.id}`, {
        id: first.id,
        title: first.title + " (updated)",
        body: first.body,
        userId: first.userId ?? 1,
      })
    );
    if (!res) return;

    setPosts((prev) => prev.map((p) => (p.id === first.id ? res.data : p)));
    showToast("成功", "已更新（PUT）");
  }

  // U: Partial Update（PATCH 示例：部分更新）
  async function patchFirstPostTitle() {
    if (posts.length === 0) return showToast("提示", "列表为空，无法更新");
    const first = posts[0];

    const res = await safeRequest(() =>
      api.patch(`/posts/${first.id}`, {
        title: first.title + " (patched)",
      })
    );
    if (!res) return;

    // PATCH 返回的可能是“部分字段合并后的结果”，这里稳妥地合并
    setPosts((prev) =>
      prev.map((p) => (p.id === first.id ? { ...p, ...res.data } : p))
    );
    showToast("成功", "已更新（PATCH）");
  }

  // D: Delete
  async function deleteFirstPost() {
    if (posts.length === 0) return showToast("提示", "列表为空，无法删除");
    const first = posts[0];

    const res = await safeRequest(() => api.delete(`/posts/${first.id}`));
    if (!res) return;

    setPosts((prev) => prev.slice(1));
    showToast("成功", "已删除（DELETE）");
  }

  // 额外：演示 responseType（blob）与 withCredentials/headers 的位置
  // 这里不直接调用，只展示你应该怎么写
  const advancedSnippets = useMemo(() => {
    return {
      downloadBlob: `api.get("/files/report.pdf", { responseType: "blob" })`,
      withCredentials: `api.get("/me", { withCredentials: true })`,
      headers: `api.get("/me", { headers: { Authorization: "Bearer <token>" } })`,
      validateStatus: `api.get("/x", { validateStatus: (s) => s < 500 })`,
    };
  }, []);

  useEffect(() => {
    fetchPosts();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  return (
    <div style={{ padding: 16, fontFamily: "system-ui, -apple-system, Segoe UI, Roboto, Arial" }}>
      <h2>Axios CRUD Demo（React / JS）</h2>

      <div style={{ display: "flex", gap: 10, flexWrap: "wrap", marginBottom: 14 }}>
        <button onClick={fetchPosts} disabled={loading}>
          {loading ? "Loading..." : "刷新列表(GET + params)"}
        </button>
        <button onClick={createPost} disabled={loading}>
          创建(POST + data)
        </button>
        <button onClick={updateFirstPost} disabled={loading}>
          更新(PUT)
        </button>
        <button onClick={patchFirstPostTitle} disabled={loading}>
          局部更新(PATCH)
        </button>
        <button onClick={deleteFirstPost} disabled={loading}>
          删除(DELETE)
        </button>
      </div>

      <div style={{ display: "grid", gap: 8, maxWidth: 520, marginBottom: 16 }}>
        <label>
          Title：
          <input
            value={title}
            onChange={(e) => setTitle(e.target.value)}
            style={{ width: "100%", padding: 8, marginTop: 4 }}
            placeholder="输入 title"
          />
        </label>
        <label>
          Body：
          <textarea
            value={body}
            onChange={(e) => setBody(e.target.value)}
            style={{ width: "100%", padding: 8, marginTop: 4, minHeight: 80 }}
            placeholder="输入 body"
          />
        </label>
      </div>

      <div style={{ marginBottom: 16 }}>
        <h3>列表（前 10 条）</h3>
        <ul style={{ paddingLeft: 18 }}>
          {posts.map((p) => (
            <li key={p.id} style={{ marginBottom: 10 }}>
              <div style={{ fontWeight: 600 }}>
                #{p.id} {p.title}
              </div>
              <div style={{ fontSize: 13, color: "#444" }}>{p.body}</div>
            </li>
          ))}
        </ul>
      </div>

      <div style={{ borderTop: "1px solid #eee", paddingTop: 12 }}>
        <h3>配置项位置示例（记住写法即可）</h3>
        <pre style={{ background: "#fafafa", padding: 12, border: "1px solid #eee", borderRadius: 8 }}>
{`responseType: ${advancedSnippets.downloadBlob}
withCredentials: ${advancedSnippets.withCredentials}
headers: ${advancedSnippets.headers}
validateStatus: ${advancedSnippets.validateStatus}`}
        </pre>
      </div>

      <Toast toast={toast} onClose={() => setToast(null)} />
    </div>
  );
}
```
