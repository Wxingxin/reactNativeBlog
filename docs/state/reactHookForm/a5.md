下面我**按真实项目常用方式**，把 **React Hook Form（RHF）表单验证的完整配置思路**给你系统讲一遍：
👉 **怎么写校验规则、怎么触发、怎么显示错误、怎么配合 UI 库**。

## 1️⃣ 最基础用法（理解 RHF 验证核心）

```tsx
import { useForm } from "react-hook-form"

type FormValues = {
  username: string
  password: string
}

export default function LoginForm() {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm<FormValues>()

  const onSubmit = (data: FormValues) => {
    console.log(data)
  }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input
        {...register("username", {
          required: "用户名不能为空",
          minLength: {
            value: 3,
            message: "至少 3 个字符",
          },
        })}
      />
      {errors.username && (
        <p style={{ color: "red" }}>{errors.username.message}</p>
      )}

      <input
        type="password"
        {...register("password", {
          required: "密码不能为空",
          minLength: {
            value: 6,
            message: "至少 6 位",
          },
        })}
      />
      {errors.password && (
        <p style={{ color: "red" }}>{errors.password.message}</p>
      )}

      <button type="submit">登录</button>
    </form>
  )
}
```

### 📌 你要记住 3 个点

| 概念                 | 作用              |
| ------------------ | --------------- |
| `register`         | 绑定 input + 校验规则 |
| `handleSubmit`     | 提交前统一校验         |
| `formState.errors` | 所有字段的错误状态       |

## 2️⃣ 常用内置校验规则大全（必须会）

```ts
register("field", {
  required: "必填",
  minLength: { value: 3, message: "最少 3 位" },
  maxLength: { value: 10, message: "最多 10 位" },
  min: { value: 1, message: "最小 1" },
  max: { value: 100, message: "最大 100" },
  pattern: {
    value: /^[a-zA-Z0-9]+$/,
    message: "只能是字母和数字",
  },
})
```

### 📌 典型使用场景

* 用户名 / 昵称 → `minLength`
* 密码 → `minLength`
* 手机号 / 邮箱 → `pattern`
* 年龄 / 金额 → `min / max`

## 3️⃣ 自定义校验（非常常用 ⭐）

### ✅ 同步校验

```ts
register("password", {
  validate: (value) =>
    value.includes("!") || "密码必须包含 !",
})
```

### ✅ 多个规则

```ts
register("password", {
  validate: {
    hasNumber: (v) => /\d/.test(v) || "必须包含数字",
    hasUpper: (v) => /[A-Z]/.test(v) || "必须包含大写字母",
  },
})
```

## 4️⃣ 校验触发时机（新手最容易忽略）

```ts
const { register } = useForm({
  mode: "onBlur",      // 失焦校验（推荐）
  // onChange           // 输入时校验
  // onSubmit           // 提交时（默认）
  // all                // 所有时机
})
```

### 📌 推荐配置（真实项目）

```ts
useForm({
  mode: "onBlur",
  reValidateMode: "onChange",
})
```

## 5️⃣ 错误状态的结构（你必须看懂）

```ts
errors = {
  username: {
    type: "required",
    message: "用户名不能为空"
  }
}
```

所以你可以这样写：

```tsx
{errors.username?.message}
```

## 6️⃣ 配合 UI 组件库（AntD / MUI / 自定义组件）

### ❗ 普通 `register` 只能用于原生 input

### ❗ 组件库必须用 `Controller`

```tsx
import { Controller, useForm } from "react-hook-form"
import { Input } from "antd"

<Controller
  name="email"
  control={control}
  rules={{
    required: "邮箱必填",
    pattern: {
      value: /^\S+@\S+$/,
      message: "邮箱格式不正确",
    },
  }}
  render={({ field }) => (
    <Input {...field} status={errors.email ? "error" : ""} />
  )}
/>

{errors.email && <span>{errors.email.message}</span>}
```

## 7️⃣ 表单整体错误（登录失败 / 后端返回）

```ts
setError("root", {
  message: "用户名或密码错误",
})
```

```tsx
{errors.root && (
  <div style={{ color: "red" }}>{errors.root.message}</div>
)}
```

---

## 8️⃣ 表单禁用 / 提交状态（体验必做）

```tsx
const {
  handleSubmit,
  formState: { isSubmitting, isValid },
} = useForm({ mode: "onChange" })

<button disabled={!isValid || isSubmitting}>
  {isSubmitting ? "提交中..." : "提交"}
</button>
```

## 9️⃣ 真实项目推荐配置（⭐直接用）

```ts
const form = useForm({
  mode: "onBlur",
  reValidateMode: "onChange",
  defaultValues: {
    username: "",
    password: "",
  },
})
```
