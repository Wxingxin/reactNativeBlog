下面给你一份 **JS + JSX** 版本的“`useForm` + `Controller` / `useController` 在项目中常见配置大全 + 知识点大全”，按真实项目使用频率和踩坑点组织。你可以把它当成团队规范文档来用。

---

## 1）核心分工：什么时候用 `register`，什么时候用 `Controller/useController`

### 用 `register`（优先）

适用于 **原生表单控件**，能直接拿到 `ref/name/onChange/onBlur` 的那类：

* `<input />`, `<textarea />`, `<select />`（原生）
* 简单 checkbox、radio

优势：代码短、性能好、最符合 RHF 设计（非受控）。

### 用 `Controller` / `useController`（高频场景）

适用于 **第三方 UI 组件** 或 **自定义组件**，它们通常：

* 不暴露 `ref`（或不按原生 input 的方式工作）
* `onChange` 回调参数不是事件而是值（例如 `onChange(value)`）
* 值字段叫 `checked`、`selected`、`date` 等，不是 `value`

典型：AntD / MUI / Radix / Headless UI 的 Select、DatePicker、Switch、Autocomplete、富文本、评分、上传等。

---

## 2）`Controller` 常见配置大全（项目最常用）

`Controller` 的本质：**把 RHF 的 field（value/onChange/onBlur/ref/name）桥接到你的组件上**。

### 2.1 最常用：`name` / `control` / `render`

```jsx
import { useForm, Controller } from "react-hook-form";

export default function Demo() {
  const { control, handleSubmit } = useForm({
    defaultValues: { status: "draft" },
    mode: "onSubmit",
    reValidateMode: "onChange",
  });

  return (
    <form onSubmit={handleSubmit(console.log)}>
      <Controller
        name="status"
        control={control}
        render={({ field, fieldState, formState }) => (
          <>
            <select {...field}>
              <option value="draft">draft</option>
              <option value="published">published</option>
            </select>

            {fieldState.error?.message && (
              <p style={{ color: "crimson" }}>{fieldState.error.message}</p>
            )}
          </>
        )}
      />
      <button>Submit</button>
    </form>
  );
}
```

**知识点**

* `field` 包含：`value`, `onChange`, `onBlur`, `name`, `ref`
* `fieldState`：**只针对当前字段**（推荐用它展示错误）
* `formState`：整表单状态（`isSubmitting/isDirty...`）

---

### 2.2 `rules`：在 Controller 上直接写校验（常用）

> 如果你没有用 Zod resolver，可以直接用 `rules`。

```jsx
<Controller
  name="price"
  control={control}
  rules={{
    required: "价格必填",
    min: { value: 1, message: "最小为 1" },
    validate: (v) => (Number.isFinite(v) ? true : "必须是数字"),
  }}
  render={({ field, fieldState }) => (
    <>
      <input
        type="number"
        value={field.value ?? ""}
        onChange={(e) => field.onChange(e.target.valueAsNumber)}
        onBlur={field.onBlur}
      />
      {fieldState.error?.message && <p>{fieldState.error.message}</p>}
    </>
  )}
/>
```

**知识点（number 最常见坑）**

* 第三方组件/自定义组件经常返回 string
* 数字字段建议：在 `onChange` 里转换成 number（或用 schema transform）

---

### 2.3 `defaultValue`：何时需要（非常重要的坑点）

在 React Hook Form v7+：

* 如果你在 `useForm({ defaultValues })` 已经提供该字段默认值，一般不需要 Controller 的 `defaultValue`
* 但在 **动态字段**、**条件渲染** 或某些组件首屏必须有值时，`defaultValue` 可能用来兜底

```jsx
<Controller
  name="category"
  control={control}
  defaultValue="" // 兜底
  render={({ field }) => <MySelect value={field.value} onChange={field.onChange} />}
/>
```

**项目建议**

* 默认值优先放在 `useForm.defaultValues`（统一入口）
* Controller 的 `defaultValue` 只用于“字段可能晚出现”的场景兜底

---

### 2.4 `shouldUnregister` 与条件字段（和 Controller 强相关）

当你用 Switch 控制字段显示时，非常常见：

```jsx
const { control, watch } = useForm({
  defaultValues: { enableExtra: false, extra: "" },
  shouldUnregister: true,
});

const enableExtra = watch("enableExtra");

{enableExtra && (
  <Controller
    name="extra"
    control={control}
    rules={{ required: "extra 必填" }}
    render={({ field, fieldState }) => (
      <>
        <input {...field} />
        {fieldState.error?.message && <p>{fieldState.error.message}</p>}
      </>
    )}
  />
)}
```

**知识点**

* `shouldUnregister: true`：隐藏字段会从提交数据里移除（更符合“隐藏就不提交”）
* `false`：隐藏字段值仍存在，可能被提交（需要你手动清理或 schema 处理）

## 3）第三方组件桥接的 6 类“必会模式”（项目最高频）

### 模式 A：组件 onChange 直接给 value（最常见）

```jsx
<MySelect
  value={field.value}
  onChange={(value) => field.onChange(value)}
  onBlur={field.onBlur}
/>
```

### 模式 B：组件 onChange 给 event（和原生一样）

```jsx
<input value={field.value} onChange={field.onChange} onBlur={field.onBlur} />
```

### 模式 C：checkbox / switch 用 `checked`

```jsx
<MySwitch
  checked={!!field.value}
  onCheckedChange={(checked) => field.onChange(checked)}
/>
```

### 模式 D：DatePicker 给 Date

```jsx
<MyDatePicker
  value={field.value || null}
  onChange={(date) => field.onChange(date)}
/>
```

### 模式 E：多选数组（tags）

```jsx
<MyMultiSelect
  value={field.value || []}
  onChange={(arr) => field.onChange(arr)}
/>
```

### 模式 F：输入需要格式化/反格式化（金额、手机号）

```jsx
<MyMoneyInput
  value={formatMoney(field.value)}
  onChangeText={(text) => field.onChange(parseMoney(text))}
  onBlur={field.onBlur}
/>
```

**知识点**

* RHF 存的应该是“业务值”（number / Date / array），不是 UI 字符串
* 格式化留在 UI 层，提交层保持干净数据

## 4）`useController`：用于封装“可复用字段组件”（项目工程化重点）

`Controller` 是组件；`useController` 是 hook。
当你要做 `RHFInput / RHFSelect / RHFSwitch` 这类封装时，**用 useController 更自然**。

### 4.1 基础封装：RHFInput（JS/JSX）

```jsx
import React from "react";
import { useController } from "react-hook-form";

export function RHFInput({ name, control, rules, label, ...props }) {
  const {
    field,
    fieldState: { error, isTouched },
  } = useController({ name, control, rules });

  return (
    <div style={{ display: "grid", gap: 6 }}>
      {label && <label>{label}</label>}
      <input {...props} value={field.value ?? ""} onChange={field.onChange} onBlur={field.onBlur} ref={field.ref} />
      {error?.message && <p style={{ color: "crimson" }}>{error.message}</p>}
      {/* isTouched 可用于“触碰后再展示错误”等 UX */}
      {isTouched && null}
    </div>
  );
}
```

使用：

```jsx
const { control, handleSubmit } = useForm({ defaultValues: { title: "" } });

<RHFInput
  name="title"
  control={control}
  label="标题"
  rules={{ required: "标题必填" }}
  placeholder="请输入标题"
/>
```

**知识点**

* `useController` 的好处：字段组件内部就能拿到 `field/fieldState`，不用每次写 `Controller render`
* 更利于统一：label、error、布局、必填标识、禁用态、help text 等

---

### 4.2 封装 Switch：处理 checked 映射（很典型）

```jsx
import React from "react";
import { useController } from "react-hook-form";

export function RHFSwitch({ name, control, rules, label, SwitchComp }) {
  const { field, fieldState } = useController({ name, control, rules });

  return (
    <div style={{ display: "flex", gap: 10, alignItems: "center" }}>
      {label && <span>{label}</span>}
      <SwitchComp
        checked={!!field.value}
        onCheckedChange={(v) => field.onChange(v)}
      />
      {fieldState.error?.message && <p style={{ color: "crimson" }}>{fieldState.error.message}</p>}
    </div>
  );
}
```

## 5）useForm 与 Controller/useController 的“常用组合配置”大全（项目可直接套）

### 5.1 通用后台表单（推荐）

```jsx
const form = useForm({
  defaultValues,
  mode: "onSubmit",
  reValidateMode: "onChange",
  shouldFocusError: true,
  shouldUnregister: true,   // 条件字段常见
  delayError: 150,
});
```

适配特点：

* 提交时校验；错了之后边改边校验
* 条件字段隐藏不提交
* 自动聚焦第一个错误

---

### 5.2 强即时反馈（注册/支付）

```jsx
const form = useForm({
  defaultValues,
  mode: "onBlur",
  reValidateMode: "onChange",
  delayError: 120,
  shouldFocusError: true,
});
```

---

### 5.3 编辑页异步回填 + 不覆盖用户已改字段（高级常用）

```jsx
const form = useForm({
  defaultValues,
  mode: "onSubmit",
  reValidateMode: "onChange",
  resetOptions: {
    keepDirtyValues: true, // 重点
  },
});
```

配合：

```jsx
useEffect(() => {
  fetchDetail().then((data) => form.reset(data));
}, []);
```

## 6）Controller/useController 的关键知识点（高频踩坑清单）

### 坑 1：第三方组件不触发 `onBlur`，导致 touched 不更新

解决：在组件合适时机手动调用 `field.onBlur()`（例如关闭下拉时）。

### 坑 2：value 类型不一致（string vs number vs boolean）

解决：

* 在 `onChange` 做转换（最常用）
* 或 schema/提交前转换（工程更稳）

### 坑 3：动态字段“首次出现”没有默认值

解决：

* 把默认值放进 `useForm.defaultValues`
* 仍不稳时，为该 Controller 加 `defaultValue` 兜底

### 坑 4：用 index 当 key 导致数组字段错位

动态数组配合 `useFieldArray` 时，渲染必须用 `field.id` 做 key。

### 坑 5：把 `field` 直接 spread 到不兼容组件

例如某些组件不接受 `name/ref`，spread 会报 warning。
解决：只传你需要的 props（`value/onChange/onBlur`）。

## 7）一份“完整可用”的综合示例（Controller + useController 同场）

场景：后台编辑页（含：Select、Switch、自定义 Input 封装、条件字段）

```jsx
import React from "react";
import { useForm, Controller } from "react-hook-form";
import { RHFInput } from "./RHFInput"; // 使用上文的封装

function FakeSelect({ value, onChange }) {
  return (
    <select value={value} onChange={(e) => onChange(e.target.value)}>
      <option value="">请选择</option>
      <option value="draft">draft</option>
      <option value="published">published</option>
    </select>
  );
}

function FakeSwitch({ checked, onCheckedChange }) {
  return (
    <button type="button" onClick={() => onCheckedChange(!checked)}>
      {checked ? "ON" : "OFF"}
    </button>
  );
}

export default function FullExample() {
  const {
    control,
    register,
    watch,
    reset,
    handleSubmit,
    formState: { errors, isSubmitting, isDirty },
  } = useForm({
    defaultValues: {
      title: "",
      status: "",
      isFeatured: false,
      featuredReason: "",
    },
    mode: "onSubmit",
    reValidateMode: "onChange",
    shouldUnregister: true,
    shouldFocusError: true,
  });

  const isFeatured = watch("isFeatured");

  // 模拟异步回填
  React.useEffect(() => {
    (async () => {
      await new Promise((r) => setTimeout(r, 300));
      reset({
        title: "Hello",
        status: "draft",
        isFeatured: true,
        featuredReason: "首页推荐",
      });
    })();
  }, [reset]);

  const onSubmit = async (data) => {
    await new Promise((r) => setTimeout(r, 500));
    console.log("submit:", data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)} style={{ display: "grid", gap: 12 }}>
      {/* useController 封装字段 */}
      <RHFInput
        name="title"
        control={control}
        label="标题"
        rules={{ required: "标题必填" }}
        placeholder="请输入标题"
      />

      {/* Controller 桥接第三方 Select */}
      <Controller
        name="status"
        control={control}
        rules={{ required: "状态必选" }}
        render={({ field, fieldState }) => (
          <div>
            <FakeSelect value={field.value} onChange={field.onChange} />
            {fieldState.error?.message && (
              <p style={{ color: "crimson" }}>{fieldState.error.message}</p>
            )}
          </div>
        )}
      />

      {/* 原生 checkbox 仍可用 register */}
      <label style={{ display: "flex", gap: 8, alignItems: "center" }}>
        <input type="checkbox" {...register("isFeatured")} />
        是否推荐
      </label>

      {/* 条件字段（依赖 shouldUnregister:true） */}
      {isFeatured && (
        <RHFInput
          name="featuredReason"
          control={control}
          label="推荐理由"
          rules={{ required: "推荐理由必填" }}
          placeholder="请输入推荐理由"
        />
      )}

      {/* 第三方 Switch（示例） */}
      <Controller
        name="isFeatured"
        control={control}
        render={({ field }) => (
          <div style={{ display: "flex", gap: 10, alignItems: "center" }}>
            <span>推荐开关：</span>
            <FakeSwitch checked={!!field.value} onCheckedChange={field.onChange} />
          </div>
        )}
      />

      {/* 全局状态示例 */}
      <button disabled={isSubmitting}>{isSubmitting ? "Saving..." : "Save"}</button>
      <small>isDirty: {String(isDirty)}</small>

      {/* 兜底展示（调试时常用） */}
      {Object.keys(errors).length > 0 && (
        <pre style={{ background: "#f6f6f6", padding: 10 }}>
          {JSON.stringify(errors, null, 2)}
        </pre>
      )}
    </form>
  );
}
```

## 8）你在项目里应该形成的“最佳实践清单”

1. **能 register 就 register**；第三方组件才上 Controller/useController
2. 默认值统一放 `useForm({ defaultValues })`，避免分散
3. 条件字段优先 `shouldUnregister: true`（隐藏不提交）
4. 字段组件封装用 `useController`（统一 label/error/layout）
5. 复杂输入（number/date/money）在 `onChange` 做类型清洗
6. 错误展示优先用 `fieldState.error`（字段级更干净）
