明白。你要的是“**原生启动屏（静态） + JS 首屏动效过渡**”这套行业标准方案：既符合 iOS/Android 启动规范，又能实现你想要的 Logo 动画、淡入淡出、缩放等过渡效果。

下面给你一套 **Expo + Expo Router 可直接落地的模板**（两种动效实现：Reanimated 或 Lottie，你任选其一）。

---

## 1) 原生启动屏（静态）先配好：`app.json`

原生启动屏只负责“App 冷启动瞬间不白屏”，动效交给 JS 首屏做。

```json
{
  "expo": {
    "name": "MyApp",
    "slug": "myapp",
    "icon": "./assets/icon.png",
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#0B1220"
    }
  }
}
```

建议：

- `backgroundColor` 选你品牌底色
- `splash.png` 放一个静态 logo（不要复杂动画）

---

## 2) 安装启动屏控制：`expo-splash-screen`

```bash
npx expo install expo-splash-screen
```

目的：**让原生启动屏别自动消失**，等 JS 动画结束再隐藏。

---

## 3) Expo Router 结构建议（清晰、好维护）

```txt
app/
  _layout.tsx
  (boot)/
    index.tsx          // 动效过渡页
  (tabs)/
    home.tsx
```

你也可以不用 `(boot)` 分组，但分组后更清晰。

---

## 4) 根布局：`app/_layout.tsx`（关键）

作用：

- 冷启动时：原生 splash 保持显示
- JS 初始化完成后：进入 boot 动画页
- 动画页结束后：再进入真正业务页面

```tsx
import { Stack } from "expo-router";
import * as SplashScreen from "expo-splash-screen";
import { useEffect, useState } from "react";

SplashScreen.preventAutoHideAsync(); // 阻止原生 splash 自动隐藏

export default function RootLayout() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    (async () => {
      // 这里做你的初始化：字体、token、配置拉取等
      // await loadFonts();
      // await restoreAuth();

      setReady(true);
    })();
  }, []);

  // 注意：此时仍然不 hide，让原生 splash 继续显示
  // JS 准备好后再渲染路由
  if (!ready) return null;

  return (
    <Stack screenOptions={{ headerShown: false }}>
      {/* boot 动画页 */}
      <Stack.Screen name="(boot)/index" />
      {/* 主应用 */}
      <Stack.Screen name="(tabs)" />
    </Stack>
  );
}
```

## 5) 动效过渡页（方案 A：Reanimated，最通用）

安装：

```bash
npx expo install react-native-reanimated
```

（Expo Managed 一般已配置好 Babel；若你项目老，需确保 babel plugin 已加。）

`app/(boot)/index.tsx`：

```tsx
import { useEffect } from "react";
import { View, Image } from "react-native";
import { useRouter } from "expo-router";
import * as SplashScreen from "expo-splash-screen";
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withTiming,
  withSequence,
  runOnJS,
} from "react-native-reanimated";

export default function BootScreen() {
  const router = useRouter();

  const opacity = useSharedValue(0);
  const scale = useSharedValue(0.92);

  const logoStyle = useAnimatedStyle(() => ({
    opacity: opacity.value,
    transform: [{ scale: scale.value }],
  }));

  const goNext = () => {
    // 动画结束后：隐藏原生 splash，再进入首页
    SplashScreen.hideAsync().finally(() => {
      router.replace("/(tabs)/home");
    });
  };

  useEffect(() => {
    // 先隐藏原生 splash 的“自动流程”由我们接管
    // 这里开始做 JS 动画
    opacity.value = withTiming(1, { duration: 280 });
    scale.value = withSequence(
      withTiming(1.02, { duration: 420 }),
      withTiming(1.0, { duration: 220 }, () => runOnJS(goNext)()),
    );
  }, []);

  return (
    <View
      style={{
        flex: 1,
        backgroundColor: "#0B1220",
        alignItems: "center",
        justifyContent: "center",
      }}
    >
      <Animated.View style={logoStyle}>
        <Image
          source={require("../../assets/logo.png")}
          style={{ width: 120, height: 120 }}
          resizeMode="contain"
        />
      </Animated.View>
    </View>
  );
}
```

你可以把动画改成：

- Logo 上移 + 标语淡入
- 先放大再缩小（弹性）
- 全屏遮罩淡出等

## 6) 动效过渡页（方案 B：Lottie，更像“开机动画”）

如果你有设计导出的 JSON 动画，用 Lottie 更合适。

安装：

```bash
npx expo install lottie-react-native
```

`app/(boot)/index.tsx`：

```tsx
import { useEffect, useRef } from "react";
import { View } from "react-native";
import { useRouter } from "expo-router";
import * as SplashScreen from "expo-splash-screen";
import LottieView from "lottie-react-native";

export default function BootScreen() {
  const router = useRouter();
  const ref = useRef<LottieView>(null);

  useEffect(() => {
    ref.current?.play();
  }, []);

  const finish = async () => {
    try {
      await SplashScreen.hideAsync();
    } finally {
      router.replace("/(tabs)/home");
    }
  };

  return (
    <View style={{ flex: 1, backgroundColor: "#0B1220" }}>
      <LottieView
        ref={ref}
        source={require("../../assets/boot.json")}
        loop={false}
        onAnimationFinish={finish}
        resizeMode="contain"
      />
    </View>
  );
}
```

---

## 7) 关键注意点（避免白屏/闪屏）

1. **不要在 `_layout.tsx` 里立刻 `hideAsync()`**
   你要把隐藏动作放到“动效页结束”那里做。

2. `_layout.tsx` 在 `ready=false` 时 `return null`
   才能确保原生 splash 继续顶住。

3. `router.replace(...)` 用 replace，不要 push
   否则用户可以 back 回启动动画页。

4. 动效页背景色要与 `splash.backgroundColor` 一致
   否则会有“颜色跳变”的闪一下。
