下面按 **Expo（托管/managed）** 的主流做法，分别说明：

1. **App 图标怎么配**
2. **开机启动页（Splash Screen）怎么配**（“开机动画/页面”在 Expo 里通常就是启动屏；若你想做“有动画的启动过渡”，需要在 JS 层再做一层）

所用配置都在 `app.json` / `app.config.js`。Expo 官方有专门文档覆盖图标与启动屏配置。([Expo Documentation][1])

---

## 一、设置 App 图标（App Icon）

### 1）准备图片

* 推荐：**1024×1024 PNG**（方形，尽量留安全边距，允许透明）
* 位置示例：`./assets/icon.png`

### 2）在 `app.json` 配置（iOS/通用）

```json
{
  "expo": {
    "name": "MyApp",
    "slug": "myapp",
    "icon": "./assets/icon.png"
  }
}
```

> `expo.icon` 是最基础的入口，会用于 iOS 以及作为默认图标来源。([Expo Documentation][1])

### 3）Android 自适应图标（强烈建议配）

Android 8+ 使用 Adaptive Icon（前景层 + 背景色/背景图）。

```json
{
  "expo": {
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#FFFFFF"
      }
    }
  }
}
```

* `foregroundImage`：通常是带透明背景的前景图（建议 1024×1024，主体别贴边）
* `backgroundColor`：自适应底色

Expo 文档对图标与自适应图标都有说明。([Expo Documentation][1])

### 4）改完图标后为什么本机没变化？

* **Expo Go** 对图标展示并不等同于独立 App
* 真正生效一般在：

  * `eas build` 生成的安装包，或
    -（如果你 prebuild 过）重新 prebuild/重装后

如果你走过 `expo prebuild`（生成过 `ios/`、`android/`），图标/启动图资源可能需要重新同步（很多人用 `expo prebuild --clean` 解决）。([Stack Overflow][2])

## 二、设置开机启动页（Splash Screen / 启动页面）

Expo 的“开机页面”是 **原生启动屏**，通过 `app.json` 的 `splash` 配置完成。([Expo Documentation][1])

### 1）准备启动图

建议准备一张 **含 logo 的 PNG**，并配一个背景色（或直接用背景图）。

### 2）在 `app.json` 配置 `splash`

```json
{
  "expo": {
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#FFFFFF"
    }
  }
}
```

* `resizeMode`：

  * `contain`：完整显示 logo（最常用）
  * `cover`：铺满屏幕，可能裁剪

这是 Expo 官方推荐的启动屏配置方式。([Expo Documentation][1])

## 三、如果你说的“开机动画”是：启动页停住，等资源加载完成再进入 App（常见需求）

这需要配合 `expo-splash-screen` 手动控制隐藏时机：

* `preventAutoHideAsync()`：阻止自动消失
* `hideAsync()`：你准备好了再隐藏
  ([Expo Documentation][3])

### Expo Router 项目典型写法（放在 `app/_layout.tsx`）

```tsx
import { Stack } from "expo-router";
import * as SplashScreen from "expo-splash-screen";
import { useEffect, useState } from "react";

SplashScreen.preventAutoHideAsync();

export default function RootLayout() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    (async () => {
      // 这里做初始化：加载字体、读取 token、预取配置等
      // await loadFonts();
      // await restoreAuth();

      setReady(true);
      await SplashScreen.hideAsync();
    })();
  }, []);

  if (!ready) return null; // 让原生 splash 继续显示

  return <Stack />;
}
```

Expo 文档明确给了“延迟隐藏启动屏”的思路，并针对 Expo Router 给了示例入口。([Expo Documentation][3])

## 四、如果你要的是“真正的启动动画”（例如 logo 缩放/淡入，随后进入首页）

原生启动屏 **本身不适合做复杂动画**（它应尽快结束）。常见正确做法是：

1. 原生 Splash：只做静态品牌页（上面 `splash`）
2. JS 首屏：做一个 `SplashTransition` 组件（Reanimated/Lottie），加载完成后导航到首页

你如果要我给一份“项目可直接用”的模板，我建议这套结构：

* 原生 splash：静态
* `app/(boot)/index.tsx`：动画启动页（1~1.5s）
* 动画结束后 `router.replace("/(tabs)/home")`

（你用的是 expo-router，我可以按你的路由结构直接给你落地代码。）

## 五、快速自查清单（避免改了不生效）

* `app.json` 路径是否正确（最常见错误：路径写错）([Stack Overflow][4])
* 图片是否为 PNG、尺寸是否足够大（图标 1024×1024 很稳）
* 你是否使用 Expo Go（不会像独立 App 那样体现图标）
* 你是否已经 prebuild 过：改完后可能需要重新 prebuild/clean 再 build ([Stack Overflow][2])
